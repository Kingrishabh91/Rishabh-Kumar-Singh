# 🔎 Intelligent Anomaly Detection

An unsupervised machine-learning project for identifying unusual observations in numeric data.

## ⚙️ Pipeline

`Raw Data → Scaling → Isolation Forest → Normal / Anomaly`

Useful for exploring fraud detection, monitoring, operational alerts, and data-quality workflows.

## 🛠️ Stack

Python • NumPy • Scikit-learn • Isolation Forest

See [`anomaly_detection.py`](./anomaly_detection.py) for the runnable demonstration.
