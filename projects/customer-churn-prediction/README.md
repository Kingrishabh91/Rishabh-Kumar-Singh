# 📉 Customer Churn Prediction

An end-to-end machine-learning project that predicts whether a customer is likely to leave a service.

### Pipeline

`Data → Cleaning → Feature Engineering → Encoding → Logistic Regression → Evaluation`

### Skills Demonstrated

- Missing-value handling
- Numerical scaling
- Categorical encoding
- Classification
- Precision / recall / F1 evaluation
- Reproducible scikit-learn pipelines

See [`train.py`](./train.py) for the implementation template.
